# sketch2026

Standalone browser-based building sketching for assessor offices, designed to integrate with SmartCAMA and other CAMA systems.

## Status

Product planning. This repository currently contains the product definition and development guidance; no application has been implemented or deployed.

## First technical milestone

Prove the geometry engine and keyboard-first browser sketch editor: exact measurements, closed outlines, classified areas and deductions, undo/redo, and save/reopen with consistent results.

Repository name is a working project identifier. Product branding, hosting, and commercial packaging remain to be decided.
