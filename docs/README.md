# Planning documents

This folder contains the planning package for **sketch2026**, a standalone browser-based building sketching product for assessor offices, with SmartCAMA as the proposed first CAMA integration.

| Document | Contents |
| --- | --- |
| [Product and build plan](product-plan.md) | Competitive research, workflows, scope, geometry requirements, integration, migration, offline work, AI, pilot criteria, and sources. |
| [Architecture](architecture.md) | Proposed components, data flow, geometry invariants, revisions, access boundaries, and CAMA exchange. |
| [Roadmap and backlog](roadmap.md) | Phased milestones, initial engineering tasks, completion criteria, and planning estimates. |
| [Complete plan in Word](Assessor_Sketch_Product_and_Build_Plan.docx) | Downloadable eight-page planning document dated September 29, 2026. |
| [Coding agent instructions](../AGENTS.md) | Development expectations, geometry rules, verification requirements, and handoff guidance. |

The Markdown documents are the working planning files. The Word document is the September 29, 2026 snapshot. Keep implementation status distinct from proposed capabilities when updating the plans.
